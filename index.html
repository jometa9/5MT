what

Self-hosted copy trading server for MT5.

How it works:

  1. Connect your MT5 accounts.
  2. Mark one as master and the rest as slaves.
  3. Every trade the master opens, modifies or closes is repeated on the slaves, about one second behind the broker.

What you need:

  • Any broker, demo or live.
  • No MT5 terminal, no EA, no Windows VPS.
  • Everything runs on your own server and is managed from a web page.

features
  • Market and pending orders, SL/TP, partial closes, modifications.
  • Lot multiplier or fixed lot, clamped to broker limits.
  • Reverse trading, symbol prefix/suffix, symbol translations, allow/block filters.
  • Exact match mode: slave mirrors master, stray orders closed.
  • Reconciles state after restarts and reconnections.
  • Password-protected web panel, works on mobile.
  • Deploy on Railway in minutes, or Docker on any server.
